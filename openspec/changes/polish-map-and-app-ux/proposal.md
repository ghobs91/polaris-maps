## Why

Polaris Maps ships a capable P2P map, but its UX lags the Apple/Google baseline in ways users notice immediately: POIs vanish below zoom 14 instead of clustering, dark mode is only half-wired, map chrome (compass, scale, heading puck, rotate/pitch) and the promised terrain mode are missing, accessibility is inconsistent, and iOS system integration stops at Live Activities and CarPlay. Closing these gaps is what turns a demo into a daily driver, and the shared animation work removes the current duplication across four bespoke sheet implementations.

## What Changes

- Cluster POIs below the individual-marker zoom instead of hiding them; render count badges that expand on tap, keep labels collision-safe, defer recomputation off-gesture to protect the 60fps budget, and cluster from cache when offline.
- Complete dark mode: every user-facing surface derives colors from the in-app theme (System/Light/Dark), gated surfaces stop calling `useColorScheme()`, hard-coded light colors are removed, and the map style follows the theme.
- Add accessibility: labels/roles/state on all map controls and selectors, Dynamic Type support without clipping, VoiceOver-friendly map and marker summaries, and contrast-checked palettes in both themes.
- Add map chrome (compass, scale bar, heading-aware location puck, rotate/pitch affordances) and complete the `terrain` style with a free/open DEM hillshade exposed in the map-type selector.
- Add iOS system integration: a home-screen widget (saved places / active-navigation ETA) and Siri/App Intents ("navigate home") that reuse existing navigation and place-list state, stay consistent with Live Activities via a shared App Group, and remain device-only and free.
- Add shared UX foundations: adopt Reanimated + Gesture Handler for one consistent sheet/animation system with unified snap thresholds and haptics, plus a toast/undo affordance for destructive actions.

## Capabilities

### New Capabilities

- `map-poi-clustering`: aggregates POIs into count/expansion cluster markers at low zoom, with collision-safe labels, a 60fps-preserving recompute strategy, and offline clustering from cached places.
- `app-dark-mode`: guarantees every user-facing surface responds to the in-app theme, gated surfaces use ThemeContext rather than `useColorScheme`, no hard-coded light colors remain, and the map style follows the theme.
- `app-accessibility`: accessibility labels/roles/state on map controls and pickers, Dynamic Type support without clipping, VoiceOver map/POI summaries, and sufficient contrast in both themes.
- `map-chrome-and-terrain`: compass, scale bar, heading-aware location puck, rotate/pitch affordances, and a completed terrain style backed by a free/open DEM hillshade.
- `ios-system-integration`: a home-screen widget for saved places / active navigation ETA and Siri/App Intents for "navigate home", built on config plugins, reusing existing app state, consistent with Live Activities, and device-only.

### Modified Capabilities

- None. No existing capability specs are present under `openspec/specs/`; all capabilities above are introduced as ADDED.

- Cross-change: coordinate DEM/imagery sourcing and attribution with the `broaden-traffic-and-media-sources` change.
